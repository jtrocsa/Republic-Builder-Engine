Why this is a POC, not a mockup

Every beat maps to a command your interpreter already runs. Nothing here needs a ninth command or a focusCamera — the hand-over is staged by moving the object, per your canon rule “a scripted beat moves characters, never the screen.”

Canon rules it demonstrates

  • Skip = fast-forward, one teardown. Skipping runs the remaining commands' end-states and still fires every setFlag — it never abandons them.
  • Flag before control. receivedCodex is written before returnControl.
  • Prompt restored. “Press E” is suppressed during the scene, back after.
  • Reduced motion respected. Toggle it; states cut instead of tween.

Where a little new PixelLab art pays off

  • Codex, larger + 2-frame glow — the current 96×128 icon scales up soft; a 2–3 frame “closed → seam-glow → open” state would sell the hand-over.
  • Director “extends / offers” pose — one frame beyond the walk set so the give reads as a give.
  • Gold dust / seam-light sprite — optional; the ambient here is canvas, which is free and parameterizable.
